# 豆豆工坊 · 拼豆 H5

按《拼豆游戏产品需求文档 V1.0》实现的移动端优先 H5 游戏。上传一张照片，把它转成带色号的拼豆图纸，逐格填豆、熨烫、入库，并导出可直接采购的材料清单。

## 运行

无需构建、无第三方依赖。可以直接双击 `index.html`（示例图已内嵌，离线也能用），或在本目录启动一个静态服务器：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

推荐用手机尺寸（390 × 844 左右）查看；桌面端会显示为居中的应用框。数据保存在浏览器 `localStorage`，清理浏览器数据会删除作品。

如果双击打开时浏览器拦截了本地文件读取（个别浏览器/安全设置），在上面的目录执行 `python3 -m http.server 8080`，再访问 `http://localhost:8080` 即可。

## 已实现（P0 为主）

- 相册上传（JPG / PNG / HEIC / WebP，超大图本地压缩），4 张内置示例图
- 裁剪：拖动、缩放、90° 旋转、镜像、1:1 / 双板比例
- 参数：单板 29×29、双板 29×58（横/竖）、四板 58×58；50 色标准板 / 30 色精简板；抖动
- 图像转换：双线性降采样 → CIELAB 最近色 → 可选的 Floyd–Steinberg 误差扩散；统计每色颗数
- 按号制作：点按、滑动连放、长按取色、双指缩放（0.5×–4×）、单指移动工具、2× 以上放大镜、色号开关、找豆呼吸提示与自动平移
- 调色盘按剩余颗数排序，填完自动打勾收起并切换到下一种颜色
- 放错颜色：豆子不落格、抖动 + 错误音，滑动时只轻提示并跳过
- 自动保存（每 10 颗、切后台、离开页面、每 30 秒），作品库续做
- 熨烫动画（4 秒，可跳过）、成品对比滑杆、统计、材料清单、采购数向上取整
- 导出成品/清单长图（PNG）、CSV、复制清单、系统分享
- 作品库：进行中 / 已完成、继续、重命名、重制、删除
- 8 步首件引导，可跳过，可从“怎么玩”重新开启

### 操作速查

| 操作 | 效果 |
| --- | --- |
| 点按空格 | 放下当前色号的豆子；错色会弹回 |
| 按住滑动 | 沿路径连续放豆，不合色自动跳过 |
| 长按格子 | 取这一格的目标色号 |
| 双指捏合 | 缩放 0.5×–4×，2× 以上自动出现放大镜 |
| 单指拖动 | 需先点「移动」工具，平移画板 |
| 「找豆」 | 当前颜色剩余空格呼吸闪烁，并自动飞到最近的一处 |
| 「色号」 | 显示/隐藏格子里的目标色号 |

## 验收口径

- 成品部件、材料清单颗数都由同一份 `grid` 统计，合计恒等于板型格数
- 建议采购数使用整数运算 `ceil(颗数 × 11 / 10)`，避免浮点误差
- 同一触摸序列内同一格只结算一次；滑动路径按 Bresenham 式采样补格
- 单板 / 双板转换在本地一次性完成，四板 3,364 格仍为毫秒级

自动化验收覆盖：全链路、错色不落格、同格连点、连续滑动、刷新续做、找豆、放大镜、熨烫、清单合计与采购数、长图/CSV 导出、作品重制、四板与 30 色、纯白图、超大文件与错误格式、双板布局、360 宽小屏。

开发辅助：控制台里 `BeadStudio.state` 可查看运行时状态；`BeadStudio.App.fillAllForTest()` 用于验收熨烫与成品页。
